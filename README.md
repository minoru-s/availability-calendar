# 空き状況カレンダー

午前・午後・夜の空き状況を示すウェブページです。

## 開発状況

現在の静的な公開版は、まず日程調整に使えるようにしたマイルストーンです。空き状況は本人が確認して手動更新しており、Google カレンダーや就活用 Google シートとの自動同期はまだ実装していません。

将来的には両方の予定を定期的に取り込み、公開用の空き状況へ反映する自動同期を追加する予定です。予定の前後に必要な準備時間などもあるため、本人が ○・△・× を調整・確認できる形を想定しています。

## 更新方法

公開する記号は `data.js` の `rules`（期間と曜日の一括設定）と `slots`（特定日の上書き）に書きます。特定日の上書きを優先し、どちらにも指定していない時間帯は ○ です。

- `available`: ○ 空き
- `tentative`: △ 調整中
- `busy`: × 予定あり

時間帯は `am`（9–12時）、`pm`（13–18時）、`night`（18–21時）です。公開時には `checkedAt` を更新し、本人が全期間を確認した場合に `reviewed` を `true` にしてください。

`data.js` は誰でも読めます。予定名、行き先、企業名などは書かないでください。

GitHub Pages には、このフォルダーのファイルをそのまま置けます。
